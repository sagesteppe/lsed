# Default per-`highway` travel speeds (km/h)

Keyed on the OSM `highway` tag; an unlisted value falls back to the
road/trail class speed. Edit or pass your own to
[`build_network`](https://sagesteppe.github.io/lsed/reference/build_network.md)
/
[`accessibility`](https://sagesteppe.github.io/lsed/reference/accessibility.md).
Drive classes are fast, foot classes ~walking.

## Usage

``` r
osm_speeds
```
